## 📋 Обзор Проекта
**Axelate** — это высокопроизводительная экосистема для локального запуска и дистрибуции ИИ-скриптов. Мы решаем проблему "ада зависимостей" и безопасности кода, предоставляя авторам защищенный маркетплейс, а пользователям — легковесный лаунчер, который не мешает работе основной системы.

## 🚀 Ключевые Философские Столпы

### 1. Экстремальная Оптимизация (0.7 MB RAM)
В отличие от тяжеловесных Electron-приложений, Axelate спроектирован как системная библиотека на **Rust**. 
* **Hibernate Mode:** При запуске генерации интерфейс (WebView) полностью выгружается из памяти.
* **Core Efficiency:** Лаунчер в трее потребляет менее **0.7 МБ**, работая исключительно как IPC-прокладка и монитор ресурсов.

### 2. Безопасность и DRM (The Fortress)
Axelate защищает интеллектуальную собственность авторов и приватность пользователей:
* **WASM Sandboxing:** Скрипты исполняются в изолированной песочнице WebAssembly.
* **TPM 2.0 Protection:** Лицензии и ключи доступа аппаратно привязаны к доверенному модулю устройства.
* **Anti-Tamper:** Защита от чтения памяти и блокировка DMA-устройств (Direct Memory Access) для предотвращения кражи весов и логики скриптов.

### 3. Справедливая Экономика
Мы верим в поддержку авторов, поэтому предлагаем лучшие условия на рынке:
* **Marketplace:** Прямая продажа скриптов пользователям.
* **Комиссия 10%:** В три раза ниже, чем в традиционных сторах (Steam/Apple).

## 🛠 Технический Стек

| Компонент | Технология | Описание |
| :--- | :--- | :--- |
| **Backend Core** | **Rust** | Строго типизированное ядро, спроектированное как библиотека. |
| **Frontend** | **Tauri + Native TS** | Высокопроизводительный UI с жесткой типизацией. |
| **IPC Bridge** | **Specta** | Типобезопасный мост между Rust и TypeScript. |
| **Scripting Runtime** | **WASM** | Мультиязычная поддержка (Python, JS, Rust) через байт-код. |
| **Storage** | **SQL (Encrypted)** | Локальная база данных для скриптов и конфигураций. |
| **AI Engines** | **Mistral / Local AI** | Модульная поддержка движков генерации текста и изображений. |

## 🏗 Архитектура Системы

1. **Launcher-as-a-Library:** Весь проект собирается как Cargo-библиотека для максимальной переиспользуемости и минимизации ошибок.
2. **Strict Typing:** Использование `tsconfig` и `Cargo` lint-профилей на максимальных уровнях строгости для исключения runtime-ошибок.
3. **Resource Monitoring:** Нативный мониторинг CPU/GPU/VRAM в реальном времени, интегрированный в системный трей.
4. **Global Navigation:** Использование `globalThis` для управления состоянием вкладок и контекстом AI.

## ⚠️ Безопасность и Ответственность
Axelate автоматически проверяет целостность системы перед запуском. В случае обнаружения попыток вмешательства в память или использования DMA-карт, выполнение скриптов блокируется для защиты данных автора.
