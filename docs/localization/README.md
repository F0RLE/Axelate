# Axelate Documentation Localizations

The English documentation in `en/` is the canonical source for current project
behavior and planning documents.

Available language folders:

- [English](en/README.md): canonical documentation
- [Русский](ru/README.md): partial localization
- [中文](zh/README.md): partial localization

Translation policy:

- keep current behavior in English first
- translate high-traffic integration and user docs next
- mark partial localizations clearly instead of implying full coverage
- do not translate future planning as shipped behavior
