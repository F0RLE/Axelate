# Support

Axelate is currently an active development project.

Use GitHub Issues for reproducible bugs and scoped feature requests. For setup and workflow questions, start with:

- `README.md`
- `docs/localization/en/GETTING_STARTED.md`
- `docs/localization/en/DEVELOPMENT_WORKFLOW.md`
- `docs/localization/en/CURRENT_STATE.md`

For security issues, follow `SECURITY.md` instead of opening a public issue.

For integration questions, use the English integration docs as the canonical
reference:

- `docs/localization/en/INTEGRATION_DEVELOPMENT.md`
- `docs/localization/en/INTEGRATION_API.md`
- `docs/localization/en/CUSTOM_INTEGRATIONS.md`
