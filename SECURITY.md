## 🚨 Reporting a Vulnerability

Flux Platform takes security seriously. If you discover a vulnerability, please report it responsibly.

> [!CAUTION]
> **DO NOT** create a public GitHub Issue for security vulnerabilities.

### How to Report
Please email explicitly to: **security@flux-platform.com**

We commit to responding within **48 hours**.
