**Flux Platform is Proprietary Software.**

We appreciate your interest! While the core kernel is closed-source, we value our community of developers and module creators.

## ⛔ Code Contributions
At this time, we **do not accept** public pull requests for the core kernel (`src-tauri`) or the main shell (`src`).

*   The source code is provided for reference only.
*   Unauthorized modification or distribution of the binary is prohibited.

## 🐛 Reporting Issues
Found a bug? We want to know!

1.  **Search**: Check [Existing Issues](https://github.com/F0RLE/flux-platform/issues) to avoid duplicates.
2.  **Report**: Open a detailed Issue including your **OS Version** and **App Version**.
3.  **Logs**: Attach relevant logs (redacted) if the issue is crash-related.
